# Icons

To complete the PWA setup, you'll need to add three icon files to this directory:

- `icon-192.png` - 192x192 PNG icon
- `icon-512.png` - 512x512 PNG icon
- `maskable-512.png` - 512x512 PNG icon with safe zone for maskable icons

## Quick Icon Generation

You can use online tools like:
- https://realfavicongenerator.net/
- https://favicon.io/
- Or create simple colored squares as placeholders

For now, you can create simple placeholder icons using any image editor or online tool.
